# 背包、装备与角色预览

更新：2026-10-19。适用于当前单格物品原型。不需要重建场景，等待 Unity 编译完成后进入 Play 即可。

## 使用

1. 按 Tab 打开背包。背包 16 格、口袋 4 格，装备槽位于角色预览下方。
2. 按住物品左键拖到目标格，松手放置。空格保留固定位置，取走前面的物品不会使后面的物品前移。同物品合并到堆叠上限，多余数量留在源格；不同物品交换位置。
3. 拖到界面外、落回源格或失焦时取消，不删除物品。拖动时目标边框绿色表示允许，红色表示拒绝。
4. 在右侧角色预览中按住左键左右拖动，可持续转动、反向和转多圈；拖出预览边界仍保持此次旋转，松手或失焦结束。预览采用平滑跟随，不会再每帧清除拖动状态。
5. 帽子、衣服、裤子、鞋子分别拖到对应装备槽。装备每格一件。卸下时拖回任意可用背包或口袋格；交换也会检查双方类型，普通材料不能进入装备槽。

测试装备：在 Play 中选择 `游戏 → 物品 → 给主角添加四件测试装备（Play）`。四件装备放进背包，背包满时先腾位置。不会自动修改场景初始物品。

当前装备提供槽位、类型约束和存档；没有新增穿衣模型、护甲数值或属性加成。样例物品没有图标时以中文首字显示。

## 扩展装备槽

在编辑模式选中玩家的 `PlayerInventory`，点击“写入默认四个装备槽”，再扩展配置列表。需要填写：

- `SlotId`：槽的永久唯一标识，例如 `head`、`torso`、`legs`、`feet`。已有存档使用后不要更改。
- `DisplayName`：界面名称。
- `AcceptedType`：允许的装备类型资源。

可以通过 `Create → 游戏 → 物品 → 装备类型` 创建新类型，填写非空、稳定的 `TypeId`。在物品定义的 `EquipmentType` 指定类型即可成为装备，堆叠上限自动为 1。同类型多个槽允许共用类型，但各自的 `SlotId` 必须不同。界面每行显示四个装备槽，更多槽自动换行。

类型资产位于 `Assets/_Project/Resources/EquipmentTypes/`。四件样例物品位于 `Assets/_Project/Data/Items/DA_Item_Basic_*.asset`，已加入物品注册表。以后新建物品后也要更新注册表，确保打包后按物品 ID 能查到资源。

## 存档

新存档版本为 2：背包、口袋保存实际 `SlotIndex`，装备同时保存稳定的 `SlotId`。装备配置换顺序时仍按 ID 还原。读档先检查全部容器的容量、物品、重复格子及装备类型，再写入；坏数据不会先清空当前物品。

仍可读取版本 1 的存档；旧格式没有格子位置，按记录顺序放回。旧存档没有装备，加载它会恢复为空装备栏。现有存档文件未被此次开发改写。

## 验证与边界

- 独立逻辑检查共 2780 条通过，其中 180 条覆盖固定格搬运、装备约束及位置存档。
- Unity 独立测试场景 23 项通过：真实 Input System 鼠标事件、任意目标格、跨容器、类型拒绝、卸装、配置扩展、预览连续拖动与反向、失焦、真实 JsonUtility 文件往返、Unity 组件序列化、重复恢复、坏存档拒绝和 v1 兼容。另有 22 项仇恨与死亡复活回归检查通过，包含死亡时关闭背包。
- 编辑器菜单 `游戏 → 工程 → 验证背包拖放、装备与预览（独立测试场景）` 可重复执行。会建立并关闭独立场景、恢复输入设置，不重建主场景。运行前保存未命名场景。
- 本轮 Unity 自动验证使用无图形模式：没有验证 GPU 渲染出的角色画面和实际拖动手感。预览渲染已改用当前 URP 支持的单相机请求，仍需在正常 Game 窗口确认画面和手感。

主要入口：`Inventory`（格子与搬运）、`EquipmentInventory`（装备规则）、`PlayerInventory`（容器配置）、`InventoryScreen`（指针与绘制）、`CharacterPreviewRig`（旋转与渲染）、`InventorySaveCodec`（存档映射）。
